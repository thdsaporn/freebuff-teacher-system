# ระบบบริหารจัดการข้อมูลครู อาจารย์ ครูฝึก (บช.ตชด.)

ระบบสารสนเทศสำหรับการจัดเก็บ ค้นหา จัดการข้อมูลประวัติครูอาจารย์ ตรวจจับและรวมข้อมูลซ้ำอัตโนมัติ (Auto-merge) จากไฟล์เอกสาร Word (`.docx`) และ Excel (`.xlsx`) ในโฟลเดอร์ พร้อมระบบพิมพ์เอกสารราชการตามแบบฟอร์มมาตรฐาน

---

## ✨ คุณสมบัติเด่นของระบบ

1. **สแกนและรวมข้อมูลซ้ำอัตโนมัติ (Smart Auto-Merge Ingestion)**:
   - สแกนไฟล์ `.docx` และ `.xlsx` จากทุกโฟลเดอร์ย่อย (เช่น `กดต`, `นสต`)
   - ตรวจจับข้อมูลครูที่มีชื่อ-นามสกุลเดียวกัน แล้วนำประวัติละเอียดจากไฟล์ Word (วุฒิ, การอบรม, ประวัติการทำงาน, รูปถ่าย) มารวมเข้ากับรายการหลักสูตรและวิชาที่สอนจาก Excel ให้อัตโนมัติ โดยไม่เกิดข้อมูลซ้ำซ้อน
2. **หน้าสำหรับพิมพ์ตามแบบฟอร์มราชการ (Official Form Printing)**:
   - **ใบประวัติ ครู อาจารย์ ครูฝึก (รายบุคคล)**: ตามแบบฟอร์มราชการ พร้อมกรอบรูปถ่าย ข้อมูลส่วนบุคคล และ ๔ ตารางประวัติ (วุฒิการศึกษา, การฝึกอบรม, ประวัติการทำงาน, ประวัติการสอน) จัดหน้า A4 สวยงาม สามารถสั่งพิมพ์หรือบันทึกเป็น PDF ได้ทันที
   - **บัญชีรายชื่อครู อาจารย์ ครูฝึก (ตารางสรุป)**: ตามแบบฟอร์มตารางสรุป พร้อมตัวเลือกกรองตามหลักสูตร (เช่น นสต., กดต., นรต.) และส่วนลงนามตรวจความถูกต้อง
3. **การจัดการข้อมูลครบวงจร (Full CRUD & Search)**:
   - เพิ่มข้อมูลครูใหม่, แก้ไขข้อมูลเดิม, ลบข้อมูล
   - เพิ่ม/ลบ แถวประวัติการศึกษา, การอบรม, การทำงาน, และวิชาที่สอนได้อย่างอิสระ
   - อัปโหลดหรือเปลี่ยนรูปถ่ายครูได้สะดวกรวดเร็ว
   - ค้นหาอัจฉริยะ (ค้นหาตาม ยศ, ชื่อ, นามสกุล, ตำแหน่ง, สังกัด, วิชาที่สอน) และแท็บตัวกรองหลักสูตร
   - ส่งออกข้อมูลเป็นไฟล์ Excel (`.xlsx`) ได้ตลอดเวลา

## 🚀 วิธีการเปิดใช้งานระบบ (Windows)

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์เดียว (ง่ายที่สุด)
1. ดับเบิ้ลคลิกที่ไฟล์ **`run.bat`**
2. ระบบจะทำการตรวจสอบและติดตั้งโปรแกรมที่จำเป็นให้อัตโนมัติ
3. หน้าจอระบบจะเปิดขึ้นมาบนเว็บเบราว์เซอร์ของคุณที่ `http://localhost:8000` พร้อมใช้งานทันที!

---

### วิธีที่ 2: รันผ่านคำสั่ง Command Prompt / Terminal
```bash
pip install -r requirements.txt
python main.py
```
จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:8000`

---

## 📁 โครงสร้างไฟล์ในระบบ

- `run.bat` : ตัวเปิดใช้งานระบบสำหรับ Windows (ดับเบิ้ลคลิกเพื่อเริ่มระบบ)
- `main.py` : เซิร์ฟเวอร์ FastAPI และ REST APIs
- `database.py` : ระบบฐานข้อมูล SQLite (`teachers.db`) และโมเดลข้อมูล
- `importer.py` : ตัวแยกข้อมูลจากไฟล์ Word/Excel และระบบรวมข้อมูลซ้ำ (Auto-merge)
- `static/index.html` : หน้าจอระบบเว็บแอปพลิเคชันและแบบฟอร์มสำหรับพิมพ์
- `uploads/photos/` : โฟลเดอร์จัดเก็บรูปถ่ายของครูอาจารย์
- `requirements.txt` : รายการแพ็กเกจที่จำเป็น
